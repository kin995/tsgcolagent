# 单任务演示指南

本文件对应竞赛材料中的“可验证效果”。演示范围限定为**一个任务**：从源码到生成测试，
再到指标与状态变化，不涉及批量实验。

## 1. 演示对象

| 项 | 值 |
|---|---|
| 任务 | 单文件单元测试生成 |
| 语言 | Python（Java 流程相同，需 JDK + Maven） |
| 模型 | 本地 Ollama（建议 `qwen2.5-coder:7b`） |
| 输出 | 一个测试文件 + 状态图 + 指标（LC / BC / AE / MS / Pass / TIR / 耗时） |

仓库内置两个可选目标：

- `examples/sample_python/inventory.py`：自研示例，含分支、异常与可变状态，适合现场跑；
- `demo/`：一份已完成的真实运行记录（absolute_value），不需要模型即可查看。

## 2. 现场演示步骤（约 3 分钟）

```bash
# 1) 启动
python -m tsgtest serve --port 8770 --open

# 2) 界面操作
#    - 源文件：examples/sample_python/inventory.py
#    - 模型：下拉选择本地模型
#    - 最大轮次：3，温度：0.5
#    - 点击「开始生成」
```

预期观察点（按顺序出现）：

1. 右侧状态从“排队中”变为“生成中”，日志出现“分析源码”；
2. 生成过程中出现测试执行、覆盖率、变异分析相关日志；
3. 完成后出现 8 个指标卡与生成的测试代码；
4. 点「复制」「下载」可取出测试文件；
5. 打开 `tsgtest_runs/<时间戳>_*/state_flow_graph.svg` 可看到状态图。

命令行等价操作：

```bash
python -m tsgtest gen examples/sample_python/inventory.py -o runs/single_task
```

## 3. 离线查看（无模型时）

界面点「查看示例运行（无需模型）」，会加载 `demo/` 中的历史运行：

| 指标 | 值 |
|---|---|
| 行覆盖 LC | 100% |
| 分支覆盖 BC | 100% |
| 断言有效性 AE | 90% |
| 变异得分 MS | 50% |
| 通过率 | 100% |
| 目标改善率 TIR | 100%（1/1） |
| 轮次 | 2 |

> 这是**历史记录**，不是当场生成的结果；现场演示时请以实际运行输出为准。

## 4. 单任务效果的说明口径

- 只陈述这一个任务的实测值，不外推为方法整体效果；
- 与“单次生成”的对比可在同一任务上手工作基线：关闭多轮修复（`--rounds 1`）再跑一次；
- 指标定义见 `metrics/paper_metrics.py`（`paper-v1` 口径），TIR 以预注册的原子目标为统计单位。
