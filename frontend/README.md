# 测试状态引导实验台

本目录是当前智能体项目的正式前端，不使用旧MutAgent演示数据。

分发状态不包含预置实验结果；实验列表初始为空。多目录、多任务数据由后端在实验启动后持续融合，测试知识引导库和测试知识智能体历史对话独立保留。

## 运行方式

正常情况下无需单独启动前端。运行项目根目录的`main.py`、`run_agent.py`、`batch_generate_tests.py`或`run_all_datasets.py`时，Python监控服务会直接提供`dist/`并自动打开：

```text
http://127.0.0.1:8765
```

前端开发时使用：

```powershell
npm install
npm run dev
```

开发服务器为`http://127.0.0.1:5173`，`/api`会转发到正式监控服务。

## 数据边界

- 前端实时读取测试状态中心中的共享TSG、状态流、任务报告、批量报告和测试知识引导库，不参与智能体路由、生成、评估或指标计算。
- “启动实验”通过后端封装调用原有`main.py`、`batch_generate_tests.py`和`run_all_datasets.py`，原终端命令保持可用；网页和终端共享同一套执行逻辑。
- 网页提交的实验采用目录级串行队列。一个目录中的全部项目和收尾报告未结束前，下一个目录保持“排队中”；前一个进程退出后自动接续。
- SSE连接只负责实时展示，前端断开不影响实验。
- 测试知识问答由后端`TestKnowledgeAgent`与已配置大模型共同完成，浏览器不直接连接大模型。
- 对话沿用后端当前实验的模型配置和密钥；密钥只保留在后端内存，不写入注册表，也不发送到浏览器。
- 对话可新建、重命名、删除并独立持久化；对话标题不等于当前任务，问题中提到实验或任务名称时才自动绑定对应上下文。
- 对话中的单元测试概念会被归纳进测试知识引导库：初始为“正在学习”，在后续真实任务中成功采用并验证两次后成为“已采纳”；报告查询和无关问题不会写入概念知识。
- 单任务与实验总览只展示论文定义的评价指标：LC、BC、AE、MS、Pass Rate、TIR、AvgExec 和 Time。内部过程分数保留在运行逻辑中，不进入报告页面。
- R2只处理D/E并立即写入独立轮次进度；R3统一处理全部C并显示“保留通过测试并定向优化”。D/E在R2后仍未恢复则形成最终失败报告，不开启R4。页面分别显示D/E原因驱动恢复和C级最小目标优化的真实状态。
- Python并行时，后端额外写入轻量`batch_runtime.json`。页面实时显示同一数据集内的任务工作槽、活动任务、等待任务和Ollama通道，并合并多个活动任务的智能体事件；运行任务不计入E级。完整共享TSG仍按单任务聚焦，不做跨任务错误合并。
- 终端使用`--knowledge-store`指定的外部长期知识路径会随实验登记传给监控服务；知识页面和测试知识智能体对话读取同一外部文件，网页启动的新任务也继承该路径。

## 页面功能

实验台默认提供“全部实验”融合总览，并可筛选正在运行、已跑完、排队中或单个实验。其余页面包括网页启动、ValiFixTest方法展示台、智能体协作、八阶段执行过程、测试状态中心、任务与报告、测试知识引导库、Python/Java系统能力和测试知识智能体多会话。ValiFixTest展示台的“提示工程”区域提供 12 条可切换查看的提示词内容，附近还有简化方法流程；验证与修复类型可点开说明。指标区包含 15 项项目指标、5 项修复阶段指标和整体统计。项目指标中的 AD 以“条/方法”显示；阶段 F2 的覆盖数据按变化量显示。页面中的统计、阶段、内部任务、节点、关系、指标、知识记录和产物文件均可点击查看详情。

详情不直接展示JSON或结构化数组，而是按数据类型转换为指标卡、比例条、分类分布、标签组和记录流。智能体协作页以共享TSG为中心展示三个正式命名的智能体节点、当前交互、事件流和内部能力证据；智能体卡片根据真实事件说明正在评估、规划、生成、验证、修复、优化、检索或学习的具体工作。测试状态中心内部事件显示为“状态迭代N”，任务实验轮次才使用R1/R2/R3。超大共享TSG文件由后端转换为专用轻量数据，在详情中展示真实节点、关系、证据节点数量、四层状态空间和类型分布。D/E任务展示具体失败原因、原始错误、各轮措施、历史经验措施和下一步建议。尚未产生数据的入口显示禁用状态，不会打开空详情。顶部“当前数据视图”只切换和融合已有数据，不会启动或重新执行任务；新实验统一从左侧“启动实验”进入。
